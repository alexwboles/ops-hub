# Back-Office OS — ops-hub

One calm dashboard for the three products that run a small business behind the scenes:

- **[sopforge-ai](https://github.com/alexwboles/sopforge-ai)** — plain-English descriptions become step-by-step SOP checklists ($15/mo)
- **[hirewise-ai](https://github.com/alexwboles/hirewise-ai)** — job-post writer, red-flag checker, resume screener, hiring pipeline ($29/mo)
- **[triagepilot-ai](https://github.com/alexwboles/triagepilot-ai)** — AI email triage (Urgent / Reply / FYI / Spam) + reply drafter ($24/mo)

## The honest connection

1. **Hire** — HireWise helps you write a fair, appealing job post and screen applicants on merit.
2. **Train** — SOPForge turns "how we do things here" into checklists the new hire follows from day one.
3. **Focus** — TriagePilot keeps the owner's inbox under control, so the owner manages the system instead of drowning in email.

No single product pretends to do the others' job. They connect because a business that hires, trains, and communicates is a business that runs itself.

## Bundle idea

Bought separately: $15 + $29 + $24 = **$68/mo**. As "Back-Office OS": **$49/mo** — a pitch, not a promise.

## Run it

Open `index.html` in any browser. No build step, no dependencies, no network calls.

- `bash test/smoke.sh` — static checks
